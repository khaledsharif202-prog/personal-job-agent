# Privacy Checklist Before Publishing

Before every public push, verify that the repository contains none of the following:

- real CV files;
- street address;
- private phone number;
- personal email address;
- authentication tokens or API secrets;
- private application messages;
- employer communications not intended for publication;
- application history that identifies private accounts;
- generated drafts containing personal contact details.

The committed `cv-profile.json` is a sample profile. Keep real profile/CV data in a local-only file or an ignored directory.
